# LIVE PRIZE

واجهة عربية تجريبية لبرنامج مكافآت بقيمة 20 دولاراً.

## الملفات
- `index.html`: واجهة الموقع.
- `styles.css`: التصميم المتجاوب.
- `app.js`: مشاركة الرابط ورسائل النموذج التجريبي.
- `PRIVACY-TERMS.md`: متطلبات الشفافية والخصوصية قبل الإطلاق.

## الحالة الحالية
هذه **واجهة أولية فقط**. زر المشاركة يشارك رابطاً يحمل رمز إحالة، لكنه لا يتحقق من أن 10 أشخاص مختلفين استقبلوا الرابط أو أكملوا التسجيل. شريط التقدم غير مفعّل، ونموذج البيانات لا يرسل أو يحفظ أي شيء. لا توجد لوحة إدارة أو دفع أو نظام استحقاق.

## متطلبات الإطلاق
1. تأكيد وجود تمويل فعلي يكفي لدفع 20 دولاراً لكل مشارك يستوفي الشروط.
2. نشر قواعد الأهلية والتحقق وحدود المشاركة وآلية مكافحة التلاعب بوضوح.
3. بناء خادم وقاعدة بيانات للتحقق من الدعوات، مع حماية من الإحالات الوهمية والتكرار.
4. إضافة لوحة إدارة محمية بمصادقة قوية وسجل تدقيق.
5. إضافة سياسة خصوصية وشروط استخدام ووسيلة دعم قبل جمع أي بيانات.
6. عدم طلب كلمات مرور أو بيانات بطاقات أو رموز تحقق من المشاركين.

## النشر
يمكن نشر الملفات الثابتة عبر GitHub Pages أو استضافة ثابتة أخرى بعد مراجعة الشروط القانونية وسياسات المتاجر/المنصات ذات الصلة. لا تضع مفاتيح سرية في المستودع.
